## Minecraft 1.21.1 — NeoForge and Fabric

EMI Tree Tabs 5.0.2 fixes a crash when leaving a world. Requires Java 21 and EMI 1.1.22 or newer; tested against EMI 1.1.24. Fabric
also requires Fabric API. YACL is optional for the in-game settings screen.

### Changes

- **No crash after leaving a world.** With tabs open, returning to the title screen could crash the
  game with `NullPointerException: ... "client.level" is null` from `EmiTagKey.registry`. The mod
  kept trying to rebuild the parked tabs every tick while no world was loaded, and EMI needs a world
  to read tags. Tabs are now rebuilt only once a world is loaded, when the next world's recipes are
  ready. On 5.0.1 the same mistake was caught instead of crashing, but it filed every tab as rejected.

Includes every 5.0.1 change.

### Compatibility and saves

Saves from 5.0.0 and 5.0.1 load unchanged. The same fix ships for Minecraft 1.20.1 on Forge/Fabric as 5.0.2.

### Verification

The automated tests pass on each Minecraft line, and CI builds every loader jar. **Checked in game on
NeoForge 1.21.1** (EMI 1.1.24, NeoForge 21.1.266, a large modpack): about nine hours of play with
tabs open, leaving and rejoining the world, with no crash and no tabs filed as rejected. Fabric was
not played. This is a GitHub-only release, not uploaded to Modrinth or CurseForge.
