## Minecraft 1.21.1 — NeoForge and Fabric

EMI Tree Tabs 5.0.0 brings the current tab, phase and crafting-list workflow to Minecraft 1.21.1.
Requires Java 21 and EMI 1.1.22 or newer; tested against EMI 1.1.24. Fabric also requires Fabric API.
YACL is optional for the in-game settings screen.

### Changes

- Attached sidebar: full window height, 25% of its width, with compact controls.
- Visible buttons for renaming, setting amounts, phase parking/focusing, closing and reopening tabs.
- Tooltips wrap to a consistent maximum width and sit beside the sidebar.
- New **EMI settings → Config Presets → Sidebars → EMI Tree Tabs** preset: Crafting, Favorites and Craftables on the left, item index on the right. Click the left header's page icon to switch list types.
- Recipe choices opens with **Ctrl+Shift+R**, preserving EMI's Ctrl+R random-tree shortcut.
- Updated README with setup screenshots and a short page-switching recording.

### Compatibility and saves

This release is for **1.21.1 only**, on **NeoForge or Fabric**. Minecraft 1.20.1 on Forge/Fabric receives the same 5.0.0 shared updates from the `mc/1.20.1` branch, published separately as [5.0.0 for 1.20.1](https://github.com/ROOCKY-dev/emi-tree-tabs/releases/tag/v5.0.0%2B1.20.1).

Before moving saved tabs between Minecraft versions, back up `config/emitreetabs-tabs.json` and `config/emitreetabs.json`. Missing recipe IDs cannot be restored, and choices for items with old NBT may fall back to EMI defaults after the move to data components. Check restored trees before relying on their totals.

### Verification

111 automated tests pass. Both loaders were playtested, including the preset. Separate startup checks passed without YACL, and the packaged metadata, mixins, refmaps and services were checked before publishing.
