## Minecraft 1.20.1 — Forge and Fabric

EMI Tree Tabs 5.0.0 brings the same shared improvements to the 1.20.1 line as the 1.21.1 release.
Requires Java 17 and EMI; tested with EMI 1.1.24. Fabric also requires Fabric API. YACL is optional
for the in-game settings screen.

- Attached sidebar: full window height, 25% of the width, with contents at 65% normal GUI size.
- Visible buttons for rename, batch amounts, phase park/focus, close and reopen.
- Wrapped tooltips placed beside the panel.
- **EMI settings → Config Presets → Sidebars → EMI Tree Tabs** sets Crafting, Favorites and
  Craftables on the left and the index on the right. Click the page icon to switch list types.
- **Ctrl+Shift+R** opens recipe choices, preserving EMI's Ctrl+R shortcut.
- README setup screenshots and the page-switching recording.

The existing 1.20.1 tab save format is retained. This is the Forge/Fabric build for **1.20.1**;
use the separate NeoForge/Fabric 5.0.0 files for **1.21.1**. Both Minecraft lines now receive shared
updates together and use the same mod version.
