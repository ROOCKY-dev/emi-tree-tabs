## Minecraft 1.20.1 — Forge and Fabric

EMI Tree Tabs 5.0.1 is a reliability update: it makes saved tabs harder to lose and keeps status
information accurate. Requires Java 17 and EMI; tested with EMI 1.1.24. Fabric
also requires Fabric API. YACL is optional for the in-game settings screen.

### Changes

- **Safer saves.** The tabs file and the config are replaced whole, never half-written. The previous
  save is kept as `emitreetabs-tabs.json.bak`; an unreadable file is moved to `.corrupt` and the tabs
  are restored from the backup.
- **Failed saves are retried** the next time the tree screen closes, with one notice instead of
  silence.
- **One damaged tab no longer stops the rest from loading.** Tabs that cannot be rebuilt, usually
  because their recipe is not loaded, are kept in `config/emitreetabs-tabs-rejected.json` instead of
  disappearing.
- **The tab limit no longer overwrites a tab.** Opening a tree with `maxTabs` tabs open now keeps
  every tab and says so. Shift-click still replaces the current tab on purpose.
- **Reopening a closed tab** respects the tab limit and no longer loses the history entry when the
  tab cannot be rebuilt.
- Progress colours update for tabs scrolled into view after the inventory changed.
- A malformed config value now resets only that key, and the log names it.
- For mod authors: crafting-list listeners are called after the list is final, a listener that
  throws is dropped as documented, and a failing integration can no longer break the others.

### Compatibility and saves

Saves from 5.0.0 load unchanged. The same changes ship for Minecraft 1.21.1 on NeoForge/Fabric as
5.0.1 for 1.21.1.
