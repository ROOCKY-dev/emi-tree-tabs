## Minecraft 1.20.1 — Forge and Fabric

**Nightly build — not a stable release.** EMI Tree Tabs 6.0.0-nightly.1 previews the 6.0 UI rework.
It is published on GitHub only, never on Modrinth or CurseForge. Requires Java 17 and EMI; tested with EMI 1.1.24.

### Changes

- **The tabs now use EMI's own GUI textures.** The horizontal strip is drawn with EMI's recipe-screen
  tabs hanging off a panel edge; the attached sidebar uses EMI's sidebar frame, item slots and
  buttons; the batch popup and the recipe-choices screen use EMI's panels too. A resource pack that
  restyles EMI (`emi:textures/gui/background.png`, `buttons.png`, `widgets.png`) now restyles
  EMI Tree Tabs with it.
- Status stays in fixed colours on top: progress, crafting mode, a phase's colour and parked trees
  look the same under every pack.
- The strip is 4px taller (26 instead of 22) so EMI's tab art fits an item icon, and its scroll
  arrows are EMI's own 12px arrows.

Includes every 5.0.2 fix.

### Compatibility and saves

Saves and config from 5.x load unchanged. The same build ships for Minecraft 1.21.1 on NeoForge/Fabric as
6.0.0-nightly.1.

### Verification

The automated tests pass on each Minecraft line and every loader jar builds. The new look was
checked against an offline mock built from EMI's textures, **not yet in game**. Expect rough edges,
and please report anything that looks wrong, including with your resource pack.
